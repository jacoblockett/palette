Automatic State Scaling

Instead of manually engineering over 40 color shades for alerts, cards, hover states, and disabled states, Palette.js dynamically computes color contrasts & alphas based on the ambient mode context.

Contrast Guard

Palette.js dynamically tests WCAG accessibility standards. It subtly adjusts hex values to guarantee AA & AAA readability scales.

Contextual Awareness

Adapts seamlessly into dark and light mode structures, generating contextual palettes relative to your environment’s base ambient text and backgrounds.

Framework Agnostic

Instant Library Implementation

Include Palette via npm or direct CDN injects to control variable spaces.

Quick Setup package.json
// Step 1: Install the package
npm i @design/palette

// Step 2: Initialize within root wrapper file
import Palette from '@design/palette';

const dynamicStyles = Palette.generate({
  seeds: {
    text: "#f8e2f2",
    background: "#0e030b",
    primary: "#e48ec7"
  }
});

// Step 3: Call dynamicStyles.apply() to paint HTML elements live.
